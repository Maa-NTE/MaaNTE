# 自动演奏

## 简介

读取 MIDI 乐谱并向游戏窗口发送键盘演奏事件，支持钢琴和吉他。

启动前请先在游戏中打开对应乐器的演奏界面，再在任务中选择相同的「演奏模式」。默认模式为钢琴。

吉他按键通过当前连接的 Maa 控制器发送。使用「桌面端-前台」等 Seize 键盘输入方式时，请保持游戏窗口在前台；在 VS Code 调试器中也应选择对应的键盘输入方式。

## 功能

### 演奏模式

- **钢琴**：音域 C4～B6（MIDI 60～95），支持完整 36 键和仅白键 21 键。
- **吉他**：音域 E3～D♯6（MIDI 52～87），使用 36 个独立按键，包含全部半音。

吉他默认键位如下，每行按从左到右的半音顺序排列：

| 音区 | 音域    | 按键                          |
| ---- | ------- | ----------------------------- |
| 低音 | E3～D♯4 | `A S D F G H J K L ; ' Enter` |
| 中音 | E4～D♯5 | `Q W E R T Y U I O P [ ]`     |
| 高音 | E5～D♯6 | `1 2 3 4 5 6 7 8 9 0 - =`     |

### MIDI 谱子

选择要演奏的 MIDI 乐谱，目前通过自定义路径指定 `.mid` 或 `.midi` 文件。

### 播放速度

控制 MIDI 谱子的播放速度。`1.0` 为原速，大于 `1.0` 加快，小于 `1.0` 减慢。

### 转调

对 MIDI 谱子进行移调，单位为半音。例如 `-12` 降低一个八度，`12` 升高一个八度，`0` 不转调。

## 配置详解

### 演奏模式

下拉选择框 `AutoPlayInstrument`，默认 `钢琴`。选项为 `钢琴`（`piano`）和 `吉他`（`guitar`），决定演奏键位及超域处理使用的音域。

### MIDI 谱子

选择 MIDI 谱子来源。

**具体实现**：下拉选择框 `MidiScoreFile`，默认 `自定义路径`。选择后提供 `MidiSettings_Custom` 子选项。

#### 自定义路径

设置 MIDI 乐谱的路径、播放速度、转调、钢琴键位模式、轨道和超域处理参数。

**具体实现**：输入框组 `MidiSettings_Custom`，包含六个输入项：

- **谱子路径**（`SongPath`）：默认 `songs/example.mid`，通过 `^.+\.(mid|midi)$` 校验。相对路径从项目根目录解析，也支持绝对路径。
- **播放速度**（`Speed`）：默认 `1.0`，通过 `^(?:[1-9]\d*(?:\.\d+)?|0\.\d+)$` 校验，需大于 0。
- **转调**（`Transpose`）：默认 `0`，通过 `^-?\d+$` 校验，单位为半音。
- **键位模式**（`KeyMode`）：默认 `36`。仅钢琴模式有效，`21` 会将半音映射到最近白键，距离相同时取较低音。吉他始终使用完整 36 键，即使此处设置为 `21` 也会保留半音。
- **解析轨道**（`Tracks`）：默认 `all`，合并所有非打击乐轨道；`melody` 自动选择音符最多的非打击乐轨道；也可填写逗号分隔的轨道索引，例如 `0,2`。
- **超域处理**（`OutOfRangeMode`）：默认 `fold`。`fold` 按八度折叠至当前乐器音域；`shift` 自动居中移调后叠加手动转调，并截断超域音符；`cut` 在手动转调后直接截断超域音符。钢琴使用 MIDI 60～95，吉他使用 MIDI 52～87。

任务配置位于 `assets/resource/tasks/AutoPlay.json`。为兼容已有任务配置，任务标识保留 `AutoPiano`。Pipeline 入口 `AutoPlay` 按所选模式进入 `AutoPiano` 或 `AutoGuitar`，MIDI 参数分别覆写两个演奏节点的 `action.param.custom_action_param`，各自保留对应的乐器模式。
